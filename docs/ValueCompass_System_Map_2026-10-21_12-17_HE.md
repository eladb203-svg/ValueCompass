# מפת רכיבי המערכת

**מטרה:** לכל רכיב — מה הוא, מאיזה סוג, ובאיזה שלב הוא נבנה. **עיקרון (החלטה מ-7.10.2026, ספר הכללים R1):** הקוד אוסף, מחשב ומחליט; ה-AI רק שופט שאלות מוגדרות, מחלץ מטקסט, מסווג כשאין מקור מובנה, וכותב טקסט. **שפה:** הגרסה באנגלית (ValueCompass_System_Map_2026-10-21_12-17_EN) היא המקור. זו תרגום.

**סוגים:** **קוד** = לוגיקה ב-backend · **עבודה** = עבודה מתוזמנת או ברקע · **DB** = מבנה במסד · **AI** = סקיל (פירוט במפרט ה-AI) · **UI** = מסך.

## 1. הזרימה

```
זיהוי חברה → בדיקת מה חסר → בחירת מקור → איסוף (ספקי מקור / חילוץ AI) → בדיקות איכות
   → השלמה / תיקון / עדכון → DB (financial_facts, extraction_items)
   → נתב פרופיל → מנוע החישוב (כולל תשובות שיפוט AI כקלט) → 4 ציונים, שווי, מחיר קנייה
   → ניתוח, רקע, חיפוש, תיק ומעקב → מסכים
```
