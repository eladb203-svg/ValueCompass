# ValueCompass – Documents

The English documents are the source of truth. The Hebrew documents are translations.
If an English document and its Hebrew translation differ, the English one wins.

## scoring/

- `value_investing_scorecards_english_updated.docx` – **source of truth.** The Buffett and Graham scorecards: criteria, weights, formulas and scoring rules.
- `value_investing_scorecards_hebrew_updated.docx` – Hebrew translation of the scorecards.

## sectors/

- `ValueCompass_Sector_Methodology_Spec_EN_FINAL.docx` – **source of truth.** Sector adaptations of the scoring (bank, insurance, income-producing real estate): which calculations and data change versus the general model.
- `ValueCompass_Sector_Methodology_Spec_HE_FINAL.docx` – Hebrew translation of the sector methodology.

## reference/

- `ValueInvestConsult - prompts AIagent.txt` – Reference only: the central prompt and rules of the earlier GPT-based assistant (Hebrew answers, Buffett/Graham analysis).
  Where this file conflicts with the scorecards (e.g., the Graham Fair Value Min formula), the scorecards win.
