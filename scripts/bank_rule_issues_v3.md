### Rule issues found in this round (literal rule applied; nothing "fixed")

1. **V5 classification uses PPNR as reported, so it cannot see the one-offs it names.** PPNR = pretax income + provision, with the loss items inside it. For **TFC FY2023** (PPNR 1.3bn, provision 2.1bn) and **KEY FY2024** (PPNR 0.0bn, provision 0.3bn) the large non-credit charges (goodwill impairment / securities repositioning, which V5 itself lists as one-off examples) lower PPNR, so the year is classified **operating** and the Graham value is "cannot be valued". Under an "ex-one-off" PPNR both years would be one-off. FLG FY2023-FY2025 are operating under either reading (provision >= PPNR or PPNR <= 0). Needs a ruling: adjust PPNR for identified one-offs (needs a filing-text/AI step) or accept the literal outcome. Not changed.
2. **V5 cause is not identified.** The rule says "year and cause flagged". The code flags the year and the quantitative basis (PPNR > 0 and provision <= PPNR); the specific cause (goodwill impairment, repositioning, tax remeasurement) is not available from XBRL and is marked "not identified from the data". C FY2017 is the only one-off year in the sample (consistent with the 2017 tax-law remeasurement, but not verified against the filing).
3. **V5 quality gate is untested by this sample.** All banks that have a Graham value have Graham quality >= 55 (lowest valued bank: USB 70.8), so the "price score hidden" path is exercised by unit tests only.
4. **V8 lower bound for the implied return.** The two-stage terminal value needs a discount rate above the 2.5% terminal growth, so the -20% bound is unreachable for the *implied return*; the search runs from 2.5% to 40%, and a price needing a rate below that is "no solution". No bank in the sample hit "no solution" (all implied returns 6.5%-9.9%, implied ROTCE 12.6%-21.8%).
5. **V8 tolerance is on value, not on the root.** Stopping at |value - price| <= $0.01 leaves the root accurate to roughly 1e-4 (rate) for low-priced banks and 1e-3 for high-priced ones (JPM, GS).
6. **V7 +/-1pp scenarios** below the V6 limit (ROTCE_norm - 1pp <= 2.5%) or with a non-positive value are shown as "not shown" and excluded from the range. In this sample no scenario was dropped.
7. **V6 also removes FLG from the Buffett price model** (ROTCE_norm -1.7%). Its Graham value is likewise "cannot be valued" under V5 (three operating loss years), so FLG has no value from either model; its quality scores (24.0 / 43.4) remain.
8. **V9 scope.** Only USB and FITB state no total CET1 requirement in the 10-K (SCB only), so their requirement is *computed* (7.1% / 7.7%) - the computation could not be cross-checked there. PNC, TFC, MTB and KEY state a total and it equals 4.5% + SCB (no mismatch). FLG states 7.0% from its capital schedule (4.5% + 2.5% conservation buffer, no SCB), so V9 does not apply. G-SIB surcharges are zero for all non-G-SIBs in the sample (assumed, not extracted); BAC/GS/JPM/C/WFC requirements are as reported.
9. **V11 FLG.** FLG's LCR is "not applicable" per the spec ruling; the 10-K never mentions the LCR, so the exemption is *not* evidenced in the filing (recorded in the extraction note). MTB and KEY keep their explicit 10-K statements.
10. **V10.** FITB's 123% is a quarter-end figure (as of 2025-12-31, from the 4Q25 earnings presentation) and stays flagged `lcr_quarter_end_not_q4_average`. For all other scored banks the value is a Q4 average; the date stored is the fiscal year-end (2025-12-31).
11. **3.3.1 note.** "window contains no credit crisis" is shown for every bank with a 2016-2025 NCO window (all banks with 6+ years); TFC (1 year) and GS (5 years) have the item missing, so no note.
