### Notes and open issues (confirmation run)

1. **KEY needed one more standard tag.** `DebtSecuritiesAvailableForSaleRealizedGainLoss` is not filed for KEY in 2024. The loss (USD 1.86bn) is under `DebtAndEquitySecuritiesGainLoss`, which I added to the securities chain (after the AFS/marketable/sale tags, before `GainLossOnInvestments`), plus a fallback of gross AFS realized gain minus loss. `DebtAndEquitySecuritiesGainLoss` covers debt *and equity* securities and may include unrealized changes, so it is a looser proxy for "net realized loss on securities" than the AFS tag. Please confirm that tag is acceptable for the rule. Other banks' loss years are unaffected (none of them has a securities-driven loss year).
2. **Tag coverage is uneven.** Per bank-year tags are listed in section 2 of the report. Several banks file no goodwill-impairment or securities tag in some years (shown as `-`; treated as zero adjustment). This matters only in loss years: C FY2017 (goodwill 0.03bn, securities tag present in 2016-17: `GainLossOnSaleOfSecuritiesNet`), TFC FY2023, KEY FY2024, FLG FY2023-25 all have the relevant tags found or a reported zero.
3. **FLG stays "cannot be valued"**: FY2023 is a goodwill-impairment one-off (adjusted PPNR 3.21bn > provision 0.83bn), but FY2024 and FY2025 are operating years (adjusted PPNR below zero, provision 1.09bn / 0.18bn). Buffett is also "cannot be valued" under V6 (ROTCE_norm -1.7%).
4. **C unchanged**: FY2017 is classified one-off with cause "tax" (PPNR already exceeds provision, pretax income 22.8bn > 0). The cause is deterministic from the data, not read from the filing.
5. **TFC FY2023 cause "goodwill impairment"** (6.08bn closes the gap of 0.77bn between provision and PPNR); the Graham value for TFC is now 48.26 with price score 3.1 (Graham quality 64.3 >= 55).
6. **Cause when both adjustments are non-zero**: the rule says "whichever closes the gap"; implemented as goodwill if it alone closes the gap, else securities if it alone does, else both ("goodwill impairment + securities losses"); if both close it alone, the larger one is named. Not exercised by this sample.
7. **V8**: the implied-return search starts at 2.5% + 0.01pp; because the value is infinite as the rate approaches the terminal growth, "below 2.5%" can occur only when the model value at that bound is below the price, which cannot happen for ROTCE_norm > 2.5%. The display is implemented and unit-tested but unreachable with V6 in force.
8. **V11**: FLG total assets were USD 87.5bn at 2025-12-31 (10-K balance sheet, verified quote in `bank_regulatory.csv`) but USD 100.2bn at 2024-12-31; the exemption evidence is the latest year-end only.
9. **Thresholds**: production thresholds are unchanged (`bank.TH`). The candidate set and the override helper now live in `scripts/threshold_parallel_run.py` (reference only); no production code imports them.
